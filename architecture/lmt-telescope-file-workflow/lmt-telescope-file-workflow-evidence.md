  tolteca/design/probes/lmt_telescope_file_workflow.py

their imports and inputs, and exercises the YAML configuration and CLI handlers.
It uses the seven read-only telescope files in
`toltec_astro_dev/run/data_lmt/tel`. Temporary YAML and SQLite outputs are created
outside the reference tree and cleaned up on exit.

- Local source with a remote `source_loc` hint opens locally while retaining the
  remote host and locality columns.

  three lissajous pointing observations; the displayed coordinate query selects
  `tcs-145609-0-2`. Loading 100 azimuth samples yields shape `(100,)`.
- The displayed discovery configuration selects two files for observation
  145609, scans 1 and 2. The no-op completes for both; DB init and ingestion
  succeed in a temporary SQLite database.
- The DB query and reopening example returns both pointing scans, with header
  integration and timestamp-span duration populated on reopening.
- The Web backend resolves scan 2 and loads source `0449+635`, ICRS coordinates
  `(72.34712708333333, 63.53595388888888)` degrees, integration
  `60.320000087609515 s` and elapsed time `68.50832509994333 s`.
  Averaging consecutive groups of ten produces 342 plotting samples.

  route smoke check, not browser execution of the Dash callbacks. The backend
