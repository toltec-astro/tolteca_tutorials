# Teaching presentations

Keep introductions to the TolTEC ecosystem and presentations of complete user
workflows here, under topic-named directories.

- [TolTECA v3 overview](tolteca-v3-overview/README.md): a 20-minute visual tour of
  the data lifecycle, KIDs processing, quicklook, products, Taco–Unity execution,
  and the developing science and operations helpdesk.

Each presentation includes editable source, required assets, build and preview
commands, applicable software versions, and links to the
[workflows](../workflows/README.md) it teaches. Publish reviewed HTML/PDF exports
from the same source revision. Workshop-specific slides live with their
[workshop](../workshops/README.md).

Developer architecture review decks are in [`../architecture/`](../architecture/README.md);
maintained software specifications remain in the owning repository's `design/`
directory. Link them as further reading. All decks share the toolchain in
[`../slides/`](../slides/).
