# Teaching presentations

Keep introductions to the TolTEC ecosystem and presentations of complete user
workflows here, under topic-named directories. No teaching deck has been added
to this fresh collection yet.

Each presentation includes editable source, required assets, build and preview
commands, applicable software versions, and links to the
[workflows](../workflows/README.md) it teaches. Publish reviewed HTML/PDF exports
from the same source revision. Workshop-specific slides live with their
[workshop](../workshops/README.md).

Architecture review decks and maintained software specifications remain in the
owning software repository's `design/` directory. Link them as further reading.
