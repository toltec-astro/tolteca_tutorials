# Runnable workflows

| Workflow | Outcome | Status |
| --- | --- | --- |
| [Inspect reference data](inspect-reference-data/README.md) | Verify a pinned telescope file and save a provenance report | Runnable starter; see its validation record |
| Plan an observation | Planner outputs and assumptions supporting a proposal | Recipe pending |
| Analyze released products | Reproducible analysis of identified archive products | Dataset and recipe pending |
| Reduce my own data | Deployment, reduction, and inspected products | Dataset and complete recipe pending |

Each workflow keeps its README, notebooks or scripts, small configurations,
expected results, and validation record together. Input data remain in the
separate reference-data repository or the identified archive release.
See [Contributing](../CONTRIBUTING.md) for authoring requirements.
