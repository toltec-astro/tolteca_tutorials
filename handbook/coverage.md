# Coverage and updates

**Edition:** 26 October 2026 draft for review. **Software scope:** TolTECA v3
orientation; each linked package guide defines its supported behavior.

This draft introduces the TolTEC measurement process and provides initial
product inspection, reduction preparation, and quality guidance. Its raw-file
examples use selected acquisitions recorded in October 2025 and May 2026. It
links to the shared workflow glossary, package guides, and instrument papers. It
has not been validated as a complete science recipe or approved as documentation
for a particular data release.

## Chapter plan

The book follows the measurement from the instrument to scientific analysis.
These are the intended main chapters; the current navigation links the material
available in this draft.

| Chapter                                           | Available in this draft                                                                               |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 1. TolTEC observations and measurements           | [Opening chapter](observations.md) with a schematic of the measurement process                        |
| 2. Finding and understanding your data            | [Product inspection](products.md); release access and illustrated product examples remain to be added |
| 3. From detector measurements to calibrated maps  | Detailed calibration and mapmaking chapter in preparation                                             |
| 4. Assessing data quality                         | [Initial quality guidance](quality.md); measured examples and applicable limits remain to be added    |
| 5. Scientific analysis                            | Compact-source and extended-emission worked examples in preparation                                   |
| 6. Reducing or reprocessing observations yourself | [Reduction preparation](reduction.md); a complete validated recipe remains to be added                |

The [raw-file reference](raw-observations.md), [analysis record](provenance.md),
and [papers](references.md) support these chapters. Polarization analysis will
require its own supported procedures and calibration guidance.

## Material still needed

| ------------------------- | ------------------------------------------------------------------------------------------ |
| Obtaining a release       | Named release, supported access route, product inventory, and access conditions            |
| Product interpretation    | Release-specific file layouts, units, uncertainty definitions, flags, and worked examples  |
| Calibration and mapmaking | Supported recipes, calibration selection, scientific checks, and validated example outputs |

| Publication               | Approved data/software citations and acknowledgement instructions                          |

For the available runnable material, consult the
[v3 tutorials](https://github.com/toltec-astro/tolteca_tutorials/tree/v3.x). For
a question about your data, contact the
[LMT Helpdesk](https://sites.google.com/umass.edu/lmthelpdesk/home) with the
information described in [the analysis record](provenance.md).
