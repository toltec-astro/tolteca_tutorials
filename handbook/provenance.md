# Keep an analysis record

Keep enough information for another astronomer to identify your inputs,
understand your choices, and repeat the comparison. Start the record when you
obtain data, and extend it as you process or analyze them.

| Record       | Include                                                                                                              |
| ------------ | -------------------------------------------------------------------------------------------------------------------- |
| Data         | Release or delivery identifier, product identifiers, observation/acquisition identifiers, retrieval date, and source |
| Software     | Package versions or source revisions, environment specification, and the recipe or notebook revision                 |
| Calibration  | Exact selected artifacts or corrections, their versions and application scope                                        |
| Processing   | Effective configuration, input selections, processing run identifiers, logs, and excluded data                       |
| Measurement  | Quantity measured, units, coordinate frame, region/aperture or model, and analysis settings                          |
| Verification | Reference comparisons, uncertainty treatment, quality notes, and remaining limitations                               |
| Outputs      | Result identifiers, saved products, figures, and the record connecting them to their inputs                          |

A data release, a software version, and a handbook edition identify different
things. Keep all three where applicable. A filesystem path helps locate a file;
it does not on its own preserve its content or provenance.

## Reporting results

Follow the selected release's data citation and acknowledgement instructions,
and cite the software and scientific methods you used. Retain a copy or dated
reference to the applicable documentation with the analysis record. Check the
release's conditions before sharing data or derived products.

For this draft handbook, record the title and date, **TolTEC Data Handbook, 26
October 2026 draft**. A released handbook's formal citation and edition history
will be provided when available.
